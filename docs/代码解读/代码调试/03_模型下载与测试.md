## 1. 下载预训练模型

## 2. 单卡测试（推理）

### 2.1 准备测试脚本

由于 mini 数据集只有 323 个样本，我们可以快速测试模型：

```bash
cd /workspace/code/cv/AutoLabel/SSL/GaussianPretrain-all/GaussianPretrain

# 创建测试脚本
cat > test_model.sh << 'EOF'
#!/bin/bash

# 设置变量
CONFIG="projects/configs/gaussianpretrain/gp_0.075_convnext_mini.py"
CHECKPOINT="checkpoints/uvtr_gp_pretrain.pth"
WORK_DIR="work_dirs/test_mini"

echo "================================================"
echo "GaussianPretrain 模型测试"
echo "================================================"
echo "配置文件: $CONFIG"
echo "模型权重: $CHECKPOINT"
echo "输出目录: $WORK_DIR"
echo "================================================"

# 创建输出目录
mkdir -p $WORK_DIR

# 运行测试
python tools/test.py \
    $CONFIG \
    $CHECKPOINT \
    --eval bbox \
    --work-dir $WORK_DIR \
    --show-dir $WORK_DIR/visualizations \
    2>&1 | tee $WORK_DIR/test_log.txt

echo "================================================"
echo "测试完成！"
echo "日志保存在: $WORK_DIR/test_log.txt"
echo "可视化结果: $WORK_DIR/visualizations/"
echo "================================================"
EOF

chmod +x test_model.sh
```

### 2.2 运行测试

```bash

./test_model.sh
```

## 3. 可视化渲染结果

GaussianPretrain 的核心是渲染 RGB 和深度图。让我们可视化渲染结果：

### 3.1 修改配置启用可视化

创建测试配置，启用渲染可视化：

```bash
cat > projects/configs/gaussianpretrain/gp_test_vis.py << 'EOF'
# 继承 mini 配置
_base_ = ['./gp_0.075_convnext_mini.py']

# 启用可视化输出
test_cfg = dict(
    save_rendered_images=True,  # 保存渲染图像
    vis_dir='work_dirs/test_vis/rendered'  # 可视化目录
)
EOF
```

### 3.2 运行可视化测试

```bash
python tools/test.py \
    projects/configs/gaussianpretrain/gp_test_vis.py \
    checkpoints/uvtr_gp_pretrain.pth \
    --show-dir work_dirs/test_vis/rendered \
    --eval bbox

# 查看生成的可视化结果
ls work_dirs/test_vis/rendered/
```

### 3.3 查看渲染结果

渲染结果会保存为 `.pkl` 文件或图像。使用以下脚本查看：

```bash
cat > visualize_results.py << 'EOF'
"""可视化渲染结果"""
import os
import cv2
import numpy as np
import pickle
from pathlib import Path

# 查找渲染结果
result_dir = 'work_dirs/test_vis/rendered'
pkl_files = list(Path(result_dir).glob('*.pkl'))

if len(pkl_files) == 0:
    print("❌ 未找到渲染结果文件")
    exit(1)

print(f"找到 {len(pkl_files)} 个结果文件")

# 读取第一个结果
pkl_file = pkl_files[0]
print(f"\n加载: {pkl_file}")

with open(pkl_file, 'rb') as f:
    results = pickle.load(f)

print(f"Keys: {list(results.keys())}")

# 可视化 RGB 渲染
if 'render_rgb' in results:
    render_rgb = results['render_rgb']  # (num_cams, H, W, 3)
    print(f"Render RGB shape: {render_rgb.shape}")

    # 保存每个相机的渲染结果
    for cam_idx in range(render_rgb.shape[0]):
        img = (render_rgb[cam_idx] * 255).astype(np.uint8)
        img = cv2.cvtColor(img, cv2.COLOR_RGB2BGR)

        save_path = f'{result_dir}/cam_{cam_idx}_rgb.png'
        cv2.imwrite(save_path, img)
        print(f"  保存: {save_path}")

# 可视化深度渲染
if 'render_depth' in results:
    render_depth = results['render_depth']  # (num_cams, H, W, 1)
    print(f"Render Depth shape: {render_depth.shape}")

    for cam_idx in range(render_depth.shape[0]):
        depth = render_depth[cam_idx, :, :, 0]

        # 归一化深度图到 0-255
        depth_vis = (depth - depth.min()) / (depth.max() - depth.min() + 1e-5)
        depth_vis = (depth_vis * 255).astype(np.uint8)
        depth_vis = cv2.applyColorMap(depth_vis, cv2.COLORMAP_JET)

        save_path = f'{result_dir}/cam_{cam_idx}_depth.png'
        cv2.imwrite(save_path, depth_vis)
        print(f"  保存: {save_path}")

print(f"\n✅ 可视化完成！结果保存在: {result_dir}/")
print(f"   - cam_*_rgb.png: 渲染的 RGB 图像")
print(f"   - cam_*_depth.png: 渲染的深度图")
EOF

python visualize_results.py
```

## 4. 简化测试（只验证前向传播）

如果只想快速验证模型能否正常运行，使用以下简化测试：

```bash
cat > test_forward.py << 'EOF'
"""快速前向传播测试"""
import torch
from mmcv import Config
from mmdet3d.datasets import build_dataset, build_dataloader
from mmdet3d.models import build_model
from mmcv.runner import load_checkpoint

print("=" * 60)
print("快速前向传播测试")
print("=" * 60)

# 1. 加载配置
cfg = Config.fromfile('projects/configs/gaussianpretrain/gp_0.075_convnext_mini.py')
print("✅ 配置加载成功")

# 2. 构建模型
model = build_model(cfg.model)
model = model.cuda()
model.eval()
print("✅ 模型构建成功")

# 3. 加载权重
checkpoint = load_checkpoint(model, 'checkpoints/uvtr_gp_pretrain.pth', map_location='cuda')
print("✅ 权重加载成功")

# 4. 构建数据集
dataset = build_dataset(cfg.data.test)
data_loader = build_dataloader(
    dataset,
    samples_per_gpu=1,
    workers_per_gpu=1,
    dist=False,
    shuffle=False
)
print(f"✅ 数据集构建成功，共 {len(dataset)} 个样本")

# 5. 测试前向传播
print("\n开始测试前向传播...")
with torch.no_grad():
    for i, data in enumerate(data_loader):
        if i >= 3:  # 只测试前3个样本
            break

        print(f"  样本 {i+1}/3...")

        # 前向传播
        result = model(return_loss=False, rescale=True, **data)

        print(f"    ✅ 前向传播成功")
        if isinstance(result, dict):
            print(f"    输出 keys: {list(result.keys())}")

print("\n" + "=" * 60)
print("✅ 前向传播测试全部通过！模型运行正常。")
print("=" * 60)
EOF

python test_forward.py
```

## 6. 常见问题

### 问题1: RuntimeError: CUDA out of memory

**症状**: 测试时显存不足

**解决方案**:

```python
# 在测试配置中添加/修改
data = dict(
    test=dict(
        pipeline=[
            # ... 其他配置
            dict(type='ResizeImages', scale_factor=0.5),  # 降采样图像
        ]
    )
)

# 或减少体素分辨率
unified_voxel_size = [0.8, 0.8, 2.0]  # 从 0.6 增加到 0.8
```

### 问题2: FileNotFoundError: checkpoint not found

**症状**: 找不到模型文件

**解决方案**:

```bash
# 检查文件是否存在
ls -lh checkpoints/

# 检查路径是否正确
pwd
ls checkpoints/gp_pretrain_convnext.pth
```

### 问题3: 测试速度很慢

**症状**: 单个样本测试超过30秒

**可能原因**:
1. 数据在网络存储上（I/O慢）
2. GPU性能不足
3. 采样密度过高

**解决方案**:
```python
# 在配置中减少采样
ray_sampler_cfg=dict(
    point_nsample=512,  # 从 1024 减半
    merged_nsample=512,
)
```

### 问题4: 渲染结果异常（全黑或全白）

**症状**: 渲染的图像没有内容

**可能原因**:
1. 高斯参数异常
2. 相机参数错误
3. 深度范围不对

**调试方法**:
```python
# 在 gaussian_head.py 的 render() 函数中添加打印
print(f"pts_xyz range: {pts_xyz.min()}, {pts_xyz.max()}")
print(f"opacity range: {opacity.min()}, {opacity.max()}")
print(f"rgb range: {rgb.min()}, {rgb.max()}")
```
