## 1. nuScenes 数据集概述

### 1.1 数据集版本对比

| 版本 | 场景数 | 样本数 | 大小 | 用途 |
|------|--------|--------|------|------|
| **v1.0-mini** | 10 | 323 | ~4.2 GB | 快速测试 |
| **v1.0-trainval** | 850 | 28,130 | ~350 GB | 完整训练 |
| **v1.0-test** | 150 | 6,008 | ~50 GB | 测试提交 |

### 1.2 数据集组成

**v1.0-trainval** 包含：
- **图像数据**: 6 个相机视角 × 28,130 帧 ≈ 169,000 张图像
- **LiDAR 数据**: 32 线 LiDAR × 28,130 帧
- **标注数据**: 3D 边界框、跟踪 ID、属性等
- **地图数据**: 4 个城市的 HD 地图（Boston, Singapore）

### 2.2 下载命令

**建议下载到容器可访问的路径**：

```bash
# 创建下载目录（选择容器可访问的位置）
mkdir -p /workspace/data/nuscenes_full
cd /workspace/data/nuscenes_full

# 方法1: 使用 wget 下载（需要登录获取链接）
# 从 nuScenes 官网获取下载链接后
wget <your_download_link_for_meta>
wget <your_download_link_for_blob01>
# ... 依次下载所有文件

# 方法2: 使用 aria2c 多线程下载（更快）
aria2c -x 16 -s 16 <download_link>

# 方法3: 使用官方 AWS S3 下载（如果可用）
aws s3 cp s3://nuscenes/v1.0-trainval/ . --recursive
```

**注意**：
- 下载时间取决于网络速度（350GB 可能需要数小时到数天）
- 建议使用断点续传工具（`wget -c` 或 `aria2c`）
- 建议下载到 `/workspace/data/` 目录下（容器内）

## 3. 解压数据集

### 3.1 解压命令

```bash
cd /workspace/data/nuscenes_full

# 解压元数据
tar -xzf v1.0-trainval_meta.tgz

# 解压所有数据包（并行解压）
for i in {01..10}; do
    echo "解压 trainval${i}..."
    tar -xzf v1.0-trainval${i}_blobs.tgz &
done
wait

echo "解压完成！"
```

## 5. 修改配置文件

### 5.1 创建完整数据集配置

```bash
cd /workspace/code/cv/AutoLabel/SSL/GaussianPretrain-all/GaussianPretrain

# 创建完整数据集配置
cat > projects/configs/gaussianpretrain/gp_0.075_convnext_full.py << 'EOF'
# 继承基础配置
_base_ = ['./gp_0.075_convnext.py']

# 数据配置
data_root = 'data/nuscenes/'

data = dict(
    samples_per_gpu=1,  # 单卡批次大小
    workers_per_gpu=4,  # 增加数据加载线程
    train=dict(
        type='NuScenesDataset',
        data_root=data_root,
        ann_file=data_root + 'nuscenes_infos_train.pkl',
        pipeline=_base_.train_pipeline,
        classes=_base_.class_names,
        modality=_base_.input_modality,
        test_mode=False,
    ),
    val=dict(
        type='NuScenesDataset',
        data_root=data_root,
        ann_file=data_root + 'nuscenes_infos_val.pkl',  # 使用真实的验证集
        pipeline=_base_.test_pipeline,
        classes=_base_.class_names,
        modality=_base_.input_modality,
    ),
    test=dict(
        type='NuScenesDataset',
        data_root=data_root,
        ann_file=data_root + 'nuscenes_infos_val.pkl',
        pipeline=_base_.test_pipeline,
        classes=_base_.class_names,
        modality=_base_.input_modality,
    )
)

# 完整训练轮数
total_epochs = 24
evaluation = dict(interval=6)  # 每6个epoch评估一次

# 学习率调度
lr_config = dict(
    policy='CosineAnnealing',
    warmup='linear',
    warmup_iters=500,
    warmup_ratio=1.0 / 3,
    min_lr_ratio=1e-3
)

# 工作目录
work_dir = './work_dirs/gp_0.075_convnext_full'
EOF

echo "✅ 创建了完整数据集配置: projects/configs/gaussianpretrain/gp_0.075_convnext_full.py"
```

## 6. 存储与性能优化

### 6.1 磁盘空间需求

| 组件 | 大小 | 说明 |
|------|------|------|
| 原始数据 | ~350 GB | 压缩包（可以删除） |
| 解压后数据 | ~350 GB | 实际使用的数据 |
| 预处理文件 | ~4 GB | .pkl 文件 |
| 训练输出 | ~100 GB | 模型权重、日志等 |
| **总计** | **~800 GB** | 包含压缩包 |
| **最小需求** | **~450 GB** | 删除压缩包后 |

### 6.2 加速数据加载

**方法1: 使用 SSD 存储**
```bash
# 如果有高速SSD挂载到容器

ln -s /path/to/ssd/nuscenes data/nuscenes
```

**方法2: 增加数据加载线程**
```python
# 在配置文件中
data = dict(
    workers_per_gpu=8,  # 从4增加到8
)
```

**方法3: 预加载到内存（如果有足够RAM）**

## 9. 故障排查

### 问题1: 下载中断

**症状**: 下载过程中网络断开

**解决**:
```bash
# 使用 wget 的断点续传
wget -c <download_link>

# 或使用 aria2c
aria2c -c -x 16 <download_link>
```

### 问题2: 解压失败

**症状**: tar: Unexpected EOF

**解决**:
```bash
# 验证压缩包完整性
tar -tzf v1.0-trainval01_blobs.tgz > /dev/null

# 如果失败，重新下载该文件
wget -c <download_link_for_blob01>
```

### 问题3: 预处理 OOM

**症状**: 运行 create_data.py 时内存不足

**解决**:
```bash
# 减少并行处理数量
PYTHONPATH=. python tools/create_data.py nuscenes \
    --root-path ./data/nuscenes \
    --out-dir ./data/nuscenes \
    --extra-tag nuscenes \
    --version v1.0-trainval \
    --workers 2  # 减少worker数量
```

### 问题4: 磁盘空间不足

**症状**: No space left on device

**解决**:
```bash
# 解压后删除压缩包
rm -f *.tgz

# 或使用边解压边删除
for i in {01..10}; do
    tar -xzf v1.0-trainval${i}_blobs.tgz && rm v1.0-trainval${i}_blobs.tgz
done
```
