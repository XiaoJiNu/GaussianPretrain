# 训练流程 - 单卡与多卡

本文档详细介绍 GaussianPretrain 的训练流程，包括单卡调试和多卡分布式训练。

---

## 📋 前提条件

- ✅ 环境验证通过（参考 `01_环境验证清单.md`）
- ✅ 数据准备完成（mini 或 full，参考 `02` 和 `04`）
- ✅ 模型能正常加载（参考 `03_模型下载与测试.md`）

## 1. 训练概述

### 1.1 两种训练模式

**预训练（Pre-training）**：
- 使用 GaussianPretrain 方法学习统一3D表示
- 通过重建 RGB、Depth、Occupancy 进行自监督学习
- 配置文件：`projects/configs/gaussianpretrain/gp_0.075_convnext.py`
- 输出：预训练权重（用于下游任务初始化）

**下游任务微调（Fine-tuning）**：
- 使用预训练权重初始化模型
- 在特定任务上微调（3D 检测、HD 地图、占用预测）
- 配置文件：`projects/configs/gaussianpretrain/uvtr_dn_ft.py` 等

### 1.2 训练时间估算

**mini 数据集（323 样本）**：

| GPU配置 | 单epoch时间 | 总时间 (6 epochs) |
|---------|-----------|-----------------|
| 1×RTX 3090 | ~5分钟 | ~30分钟 |
| 1×V100 32GB | ~3分钟 | ~18分钟 |

**完整数据集（28,130 样本）**：

| GPU配置 | 单epoch时间 | 总时间 (24 epochs) |
|---------|-----------|-----------------|
| 1×RTX 3090 | ~72小时 | ~72天（不推荐） |
| 8×RTX 3090 | ~9小时 | ~9天 |
| 8×V100 32GB | ~6小时 | ~6天 |

**结论**：完整数据集**必须使用多卡训练**

### 3.3 分布式训练详解

**dist_train.sh 脚本内容**：
```bash
#!/usr/bin/env bash

CONFIG=$1
GPUS=$2
PORT=${PORT:-29500}

PYTHONPATH="$(dirname $0)/..":$PYTHONPATH \
python -m torch.distributed.launch \
    --nproc_per_node=$GPUS \
    --master_port=$PORT \
    $(dirname "$0")/train.py \
    $CONFIG \
    --launcher pytorch \
    ${@:3}
```

**关键参数**：
- `--nproc_per_node`: 每个节点的 GPU 数量
- `--master_port`: 分布式通信端口
- `--launcher pytorch`: 使用 PyTorch 分布式后端

## 6. 常见问题与优化

### 问题1: CUDA Out of Memory (OOM)

**症状**:
```
RuntimeError: CUDA out of memory. Tried to allocate 2.34 GiB
(GPU 0; 23.70 GiB total capacity; 20.12 GiB already allocated)
```

**解决方案**:

**方案1: 减小 batch size**
```python
# 在配置中
data = dict(
    samples_per_gpu=1,  # 默认
)
```

**方案2: 增大体素大小（降低分辨率）**
```python
# 修改配置
unified_voxel_size = [0.1, 0.1, 2.0]  # 从 0.075 改为 0.1
```

**方案3: 减少采样点数**
```python
ray_sampler_cfg = dict(
    point_nsample=512,      # 从 1024 减半
    merged_nsample=512,     # 从 1024 减半
)
```

**方案4: 启用梯度检查点（Gradient Checkpointing）**
```python
# 在模型配置中
model = dict(
    use_checkpoint=True,  # 启用梯度检查点
)
```

**方案5: 使用混合精度训练（FP16）**
```python
# 配置中已默认启用
fp16 = dict(loss_scale='dynamic')
```

### 问题2: 训练速度慢

**可能原因**:
1. 数据加载成为瓶颈
2. 磁盘 I/O 慢
3. GPU 利用率低

**解决方案**:

**优化1: 增加数据加载线程**
```python
data = dict(
    workers_per_gpu=8,  # 从 4 增加到 8
)
```

**优化2: 使用 SSD 存储数据**
```bash
# 将数据复制到高速 SSD
cp -r /home/yr/yr/data/nuscenes /ssd/nuscenes
ln -sf /ssd/nuscenes data/nuscenes
```

**优化3: 启用持久化 workers**
```python
data = dict(
    persistent_workers=True,  # 保持worker进程
)
```

**优化4: 预先编译 CUDA 扩展**
```bash
# 确保所有 CUDA 扩展已编译
cd projects/mmdet3d_plugin/ops/diff-gaussian-rasterization
python setup.py develop
```

### 问题3: 分布式训练挂起

**症状**:
- 训练卡在 "waiting for other processes"
- 多卡同步失败

**解决方案**:

**检查1: 端口冲突**
```bash
# 更换通信端口
PORT=29501 bash tools/dist_train.sh config.py 8
```

**检查2: NCCL 环境变量**
```bash
# 设置 NCCL 调试信息
export NCCL_DEBUG=INFO
export NCCL_IB_DISABLE=1  # 禁用 InfiniBand（如果有问题）

bash tools/dist_train.sh config.py 8
```

**检查3: 网络配置**
```bash
# 检查网络接口
ifconfig

# 指定网络接口
export NCCL_SOCKET_IFNAME=eth0
```

### 问题4: 损失不下降 / NaN

**症状**:
- `loss: nan`
- 损失在前几个 iteration 就爆炸

**解决方案**:

**检查1: 学习率过大**
```python
optimizer = dict(
    lr=1e-4,  # 从 2e-4 降低到 1e-4
)
```

**检查2: 梯度裁剪**
```python
optimizer_config = dict(
    grad_clip=dict(max_norm=35, norm_type=2)  # 启用梯度裁剪
)
```

**检查3: 数据预处理异常**
```python
# 检查数据范围
import torch
from mmdet3d.datasets import build_dataset
dataset = build_dataset(cfg.data.train)
sample = dataset[0]
print("img range:", sample['img'].data.min(), sample['img'].data.max())
```

**检查4: 预训练权重不匹配**
```bash
# 检查权重键是否匹配
python -c "
import torch
ckpt = torch.load('checkpoints/gp_pretrain.pth')
print(list(ckpt['state_dict'].keys())[:10])
"
```

## 7. 性能优化技巧

### 7.1 数据并行 vs 模型并行

**数据并行（推荐）**：
- 每个 GPU 运行完整模型
- 数据分片到各 GPU
- 适用于大多数情况

```python
# 默认使用数据并行
# 8卡训练，每卡 batch_size=1，总 batch_size=8
```

**模型并行（不常用）**：
- 模型分片到多个 GPU
- 适用于模型太大单卡装不下
- GaussianPretrain 通常不需要

### 7.2 混合精度训练 (FP16)

**默认配置已启用**：
```python
fp16 = dict(loss_scale='dynamic')
```

**效果**：
- 显存占用减少约 50%
- 训练速度提升约 30%
- 精度损失极小（< 0.5% NDS）

### 7.3 优化采样策略

**减少光线采样数**（在 `ray_sampler_cfg` 中）：
```python
ray_sampler_cfg = dict(
    point_nsample=512,           # 点采样数（默认 1024）
    anchor_gaussian_interval=50, # 深度采样数（默认 100）
)
```

**效果**：
- 显存占用减少约 30%
- 训练速度提升约 20%
- 精度损失约 1-2% NDS

## 8. 训练脚本示例

### 8.1 完整训练脚本

```bash
#!/bin/bash
# train_gp.sh - 完整的 GaussianPretrain 训练脚本

set -e  # 遇到错误立即退出

# 配置参数
CONFIG="projects/configs/gaussianpretrain/gp_0.075_convnext.py"
GPUS=8
WORK_DIR="work_dirs/gp_pretrain_$(date +%Y%m%d_%H%M%S)"
PORT=29500

# 检查环境
echo "检查环境..."
python -c "import torch; assert torch.cuda.is_available(), 'CUDA not available'"
python -c "from diff_gaussian_rasterization import GaussianRasterizer"

# 检查数据
echo "检查数据..."
test -f data/nuscenes/nuscenes_infos_train.pkl || {
    echo "错误: 训练数据未准备"
    exit 1
}

# 开始训练
echo "开始训练..."
echo "配置: $CONFIG"
echo "GPU数: $GPUS"
echo "工作目录: $WORK_DIR"

PORT=$PORT bash tools/dist_train.sh \
    $CONFIG \
    $GPUS \
    --work-dir $WORK_DIR \
    2>&1 | tee $WORK_DIR/train_$(date +%Y%m%d_%H%M%S).log

echo "训练完成！"
echo "检查点保存在: $WORK_DIR"
```

使用方法：
```bash
chmod +x train_gp.sh
./train_gp.sh
```

### 8.2 自动恢复脚本

```bash
#!/bin/bash
# resume_train.sh - 自动从最新检查点恢复训练

WORK_DIR="work_dirs/gp_pretrain"
LATEST_CKPT="$WORK_DIR/latest.pth"

if [ -f "$LATEST_CKPT" ]; then
    echo "从检查点恢复: $LATEST_CKPT"
    bash tools/dist_train.sh \
        projects/configs/gaussianpretrain/gp_0.075_convnext.py \
        8 \
        --work-dir $WORK_DIR \
        --resume-from $LATEST_CKPT
else
    echo "未找到检查点，开始新训练"
    bash tools/dist_train.sh \
        projects/configs/gaussianpretrain/gp_0.075_convnext.py \
        8 \
        --work-dir $WORK_DIR
fi
```
