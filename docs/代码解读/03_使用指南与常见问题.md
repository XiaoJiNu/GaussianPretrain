### 1.3 配置文件详解

#### 预训练配置示例 (`gp_0.075_convnext.py`)

```python
# 继承基础配置
_base_ = [
    "../_base_/datasets/nus-3d.py",
    "../_base_/default_runtime.py",
]

# 启用插件系统
plugin = True
plugin_dir = "projects/mmdet3d_plugin/"

# ===== 3D空间配置 =====
point_cloud_range = [-54.0, -54.0, -5.0, 54.0, 54.0, 3.0]
unified_voxel_size = [0.6, 0.6, 1.6]  # 关键参数：控制体素分辨率
# 0.075 vs 0.1: 更小的体素提供更精细的3D表示，但需要更多内存

# 计算体素形状
unified_voxel_shape = [
    int((point_cloud_range[3] - point_cloud_range[0]) / unified_voxel_size[0]),
    int((point_cloud_range[4] - point_cloud_range[1]) / unified_voxel_size[1]),
    int((point_cloud_range[5] - point_cloud_range[2]) / unified_voxel_size[2]),
]
# 结果: [180, 180, 5] 体素

# ===== 模型配置 =====
model = dict(
    type="UVTRGP",  # 主检测器类型

    # 图像骨干网络
    img_backbone=dict(
        type="MaskConvNeXt",  # 支持掩码的ConvNeXt
        arch="small",         # 模型大小: tiny/small/base/large
        drop_path_rate=0.2,   # 正则化参数
        out_indices=(3),      # 输出第3个stage的特征
        norm_out=True,
        frozen_stages=1,      # 冻结前1个stage
        init_cfg=dict(
            type="Pretrained",
            checkpoint="convnextS_1kpretrained_official_style.pth",
        ),
        mae_cfg=dict(
            downsample_scale=32,
            downsample_dim=768,
            mask_ratio=0.3,    # MAE风格的掩码比例
            learnable=False
        ),
    ),

    # 颈部网络
    img_neck=dict(
        type="CustomFPN",
        in_channels=[768],
        out_channels=256,
        num_outs=1,
    ),

    # 深度预测头
    depth_head=dict(
        type="ComplexDepth",  # 或 "SimpleDepth"
        use_dcn=False,
        aspp_mid_channels=96
    ),

    # GaussianHead配置
    pts_bbox_head=dict(
        type="GaussianHead",
        in_channels=256,
        unified_voxel_size=unified_voxel_size,
        unified_voxel_shape=unified_voxel_shape,
        pc_range=point_cloud_range,
        cam_nums=6,

        # ===== 光线采样配置 =====
        ray_sampler_cfg=dict(
            close_radius=3.0,              # 最小采样距离（米）
            far_radius=50.0,               # 最大采样距离（米）
            only_img_mask=False,           # 是否只在掩码区域采样
            only_point_mask=False,         # 是否只在点云区域采样
            replace_sample=False,          # 采样是否放回
            point_nsample=1024,            # 每相机采样点数
            point_ratio=0.99,              # 点采样比例
            pixel_interval=4,              # 像素采样间隔
            sky_region=0.4,                # 跳过天空（上部40%）
            merged_nsample=1024,           # 总采样数
            anchor_gaussian_interval=100,  # 沿光线的深度bin数
        ),

        # ===== 视角变换配置 =====
        view_cfg=dict(
            type="Uni3DVoxelPoolDepth",
            frustum_range=[0, 0, 1.0, 1600, 928, 60.0],
            frustum_size=[32.0, 32.0, 0.5],
            depth_dim=64,  # 深度通道数
        ),

        # ===== 渲染卷积配置 =====
        render_conv_cfg=dict(
            out_channels=32,
            kernel_size=3,
            padding=1,
        ),

        # ===== 高斯参数回归器配置 =====
        gs_cfg=dict(
            type='GSRegresser',  # 或 'GSRegresser_Resnet'
            head_dim=32,
            max_scale=0.2,  # 限制高斯最大尺寸
            fp16_enabled=False,
        ),

        # ===== 损失配置 =====
        loss_cfg=dict(
            weights=dict(
                rgb_loss=1.0,           # RGB重建损失权重
                depth_loss=0.1,         # 深度重建损失权重
                opacity_loss=0.0,       # 透明度L1损失权重
                opacity_focal_loss=0.5, # 透明度Focal损失权重
                alpha=0.25,             # Focal loss alpha
                gamma=2.0,              # Focal loss gamma
            )
        ),
    ),
)

# ===== 训练配置 =====
optimizer = dict(
    type='AdamW',
    lr=2e-4,
    weight_decay=0.01
)

optimizer_config = dict(grad_clip=dict(max_norm=35, norm_type=2))

lr_config = dict(
    policy='CosineAnnealing',
    warmup='linear',
    warmup_iters=500,
    warmup_ratio=1.0 / 3,
    min_lr_ratio=1e-3
)

total_epochs = 24
evaluation = dict(interval=24)  # 每24 epochs评估一次

# ===== 运行时配置 =====
runner = dict(type='EpochBasedRunner', max_epochs=total_epochs)
checkpoint_config = dict(interval=1)  # 每epoch保存checkpoint
log_config = dict(
    interval=50,
    hooks=[
        dict(type='TextLoggerHook'),
        dict(type='TensorboardLoggerHook')
    ]
)

# FP16训练（可选，节省显存）
fp16 = dict(loss_scale=32.0)
```

- 渲染(6个视角): ~150ms

## 3. 常见问题 (FAQ)

### Q1: ImportError: cannot import name 'GaussianRasterizer'

**问题**: diff-gaussian-rasterization未正确编译

**解决方案**:
```bash
cd projects/mmdet3d_plugin/ops/diff-gaussian-rasterization
python setup.py develop --verbose

# 检查编译输出，确保无错误

# 验证安装
python -c "from diff_gaussian_rasterization import GaussianRasterizer; print('OK')"
```

**常见编译错误**:
- CUDA版本不匹配: 确保 `nvcc --version` 输出11.1
- glm库未找到: 检查 `third_party/glm/` 目录是否存在

### Q2: RuntimeError: CUDA out of memory

**问题**: GPU显存不足

**解决方案** (按优先级):
1. **减小体素分辨率** (效果最好):
   ```python
   unified_voxel_size = [0.8, 0.8, 2.0]
   ```

2. **减少光线采样**:
   ```python
   point_nsample=512
   anchor_gaussian_interval=50
   ```

3. **启用FP16**:
   ```python
   fp16 = dict(loss_scale=512.0)
   ```

4. **减少相机数** (如果可以):
   ```python
   cam_nums=4  # 只用前、后、左、右4个相机
   ```

**显存需求参考** (batch=1):
- V100 32GB: 可以跑 0.6 voxel_size
- RTX 3090 24GB: 需要 0.8 voxel_size 或 FP16
- RTX 2080Ti 11GB: 需要 1.0 voxel_size + FP16

### Q3: 损失为NaN或Inf

**问题**: 数值不稳定

**可能原因和解决方案**:

1. **学习率过大**:
   ```python
   lr=1e-4  # 从2e-4降低
   ```

2. **高斯参数爆炸**:
   ```python
   # 检查max_scale是否过大
   gs_cfg=dict(
       max_scale=0.1,  # 从0.2降低
   )
   ```

3. **深度预测异常**:
   ```python
   # 在depth_net输出后添加clip
   _depth = torch.clamp(_depth, min=1e-5, max=100.0)
   ```

4. **透明度为0导致除零**:
   ```python
   # 在loss计算中添加epsilon
   opacity = torch.clamp(opacity, min=1e-5, max=1-1e-5)
   ```

5. **检查数据**:
   ```python
   # 在forward中添加断言
   assert not torch.isnan(img).any(), "Input image contains NaN"
   assert not torch.isnan(points[0]).any(), "Points contain NaN"
   ```

## 4. 高级使用

### 4.1 自定义高斯参数

如果想预测更多参数（如球谐系数）：

```python
# 在 gs_param_network.py 中添加新的头部
class GSRegresser(BaseModule):
    def __init__(self, ...):
        ...
        # 新增: 球谐系数头 (预测SH degree 3的系数)
        self.sh_head = nn.Sequential(
            nn.Conv3d(32, 32, kernel_size=3, padding=1),
            nn.ReLU(inplace=True),
            nn.Conv3d(32, 48, kernel_size=3, padding=1),  # 16个SH系数 × 3通道
        )

    def forward(self, uni_feats):
        ...
        sh_out = self.sh_head(uni_feats)

        return {
            ...,
            'sh': self.flatten_vector(sh_out),
        }

# 在 gaussian_renderer.py 中使用SH
def render(..., sh_coeffs=None):
    rendered_rgb, radii, rendered_depth = rasterizer(
        ...,
        shs=sh_coeffs,  # 传入SH系数
        colors_precomp=None,  # 不直接使用RGB
    )
```

### 4.2 集成到其他框架

GaussianPretrain的核心思想可以迁移到其他框架：

**集成到BEVFormer**:

**集成到Occupancy Network**:

3. 联合优化几何和语义

### 6.2 超参数调优

重要超参数的调优范围：

| 参数 | 默认值 | 调优范围 | 影响 |
|------|--------|----------|------|
| `voxel_size` | 0.6 | [0.4, 1.0] | 精细度 vs 速度 |
| `max_scale` | 0.2 | [0.1, 0.3] | 高斯尺寸 |
| `point_nsample` | 1024 | [512, 2048] | 采样密度 |
| `rgb_loss` | 1.0 | [0.5, 2.0] | RGB权重 |
| `depth_loss` | 0.1 | [0.05, 0.5] | 深度权重 |
| `lr` | 2e-4 | [1e-4, 5e-4] | 学习率 |

**调优策略**:
1. 先固定其他参数，调 `voxel_size`
2. 然后调损失权重
3. 最后微调学习率
